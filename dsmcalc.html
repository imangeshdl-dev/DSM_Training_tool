Base DSM Formula:
Base DSM = -(Under-Injection MW × Effective Rate P/kWh × 2.5)
Add DSM Penalty Formula:
Add DSM Penalty = -[S1(20%) + S2(40%) + S3(100%)] × Effective Rate × 2.5
Sign Change Rule Penalty (20%):
20% extra charge on absolute base DSM if 6 consecutive blocks maintain same sign.
Total DSM Settlement:
Total DSM Settlement = Base DSM + Add DSM Penalty + Sign Change Penalty
